# Sort-a-ton

## Repository
https://github.com/M1CHAELjr/proposal.md.git

## Description
In the sort-a-ton, the purpose is to sort out your files in an easy to
see manner. This will include file types, or by file name. Relevant to
media so artist can see the different works they have done sorted by
program or name.

## Features
- Feature 1
  - Will sort files after program is run from selection
- Feature 2
  - Will be able to sort files by file extension
- Feature 3
  - Will be able to sort the files by name

## Challenges
- Will need to research or relearn, how to pull or select a section of
files to be run by the program
  - May use user input here if possible
- How to make sure when the program is run, files are actually sorted

## Outcomes
Ideal Outcome:
- The user would input the file selection and the files to be sorted, and 
the program would approriatley sort them

Minimal Viable Outcome:
- The program can sort files by file type
